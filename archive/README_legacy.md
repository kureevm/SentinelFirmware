# SentinelFirmware

Прошивка для `ESP32-S3-DevKitC-1-N8` (8 МБ flash, без PSRAM), экрана
ST7789 и трёх кнопок. Проект собирается через PlatformIO с Arduino framework.

## Сборка

В обычном терминале:

```bash
platformio run
```

Если `platformio` не находится в `PATH` на macOS:

```bash
~/.platformio/penv/bin/platformio run
```

## Настройка Wi-Fi

Прошивка не содержит SSID и пароль по умолчанию и не пытается подключаться к
фиктивной сети при загрузке.

1. Скопируйте `include/wifi_credentials.example.h` в
   `include/wifi_credentials.h`.
2. Укажите SSID и пароль в локальном файле.
3. Не добавляйте этот файл в Git — он уже указан в `.gitignore`.

Пароль не печатается в Serial Monitor; выводится только длина пароля.

## WiFi CSI

Пункт `WiFi CSI` подключает плату к настроенной сети и включает CSI API
ESP32-S3. Экран показывает:

- число принятых CSI-кадров и текущую частоту кадров;
- RSSI последнего кадра;
- среднее `|I| + |Q|` по поднесущим;
- сглаженное изменение этой величины (`Delta EMA`).

Это диагностические радиометрические данные. Они не являются определением
человека, позы, дыхания или пульса. Кнопки: верхняя сбрасывает статистику,
средняя возвращает в меню, нижняя останавливает/запускает монитор.

## Совместимость с RuView

Плата совместима с базовым сбором Wi-Fi CSI: ESP32-S3 поддерживается, 8 МБ
flash достаточно. Однако текущая полноценная прошивка RuView — отдельный
ESP-IDF-проект и не является библиотекой, которую можно просто добавить к
этому Arduino-проекту. Её прошивка заменит SentinelFirmware и его интерфейс.

Для N8 без PSRAM безопасный профиль RuView должен отключать как минимум
встроенный AMOLED-дисплей и WASM runtime. Базовый CSI и ограниченная
edge-обработка могут работать во внутренней SRAM, но доступный запас памяти
нужно проверять на конкретной сборке. Для полного RuView предпочтительна
отдельная плата с PSRAM и несколько пространственно разнесённых CSI-узлов.

Встроенный в Sentinel экран `WiFi CSI` не отправляет бинарные кадры RuView и
не заменяет RuView sensing server. Это самостоятельный локальный монитор для
проверки того, что CSI реально поступает на этой плате.
